# Skill: revisar-complejidad

## Objetivo

Identificar zonas del código con elevada complejidad.

## Cuándo debe utilizarse

Tras la revisión de Clean Code.

## Conocimiento para el agente

Evaluar:

- complejidad ciclomática
- anidamientos
- tamaño de funciones
- tamaño de clases
- dependencias excesivas

## Resultado esperado

Guardar en MCP Memory los elementos complejos asociados al `audit_id`.
