# Skill: detectar-arquitectura

## Objetivo

Identificar la arquitectura utilizada por el proyecto.

## Cuándo debe utilizarse

Después de analizar la estructura del proyecto.

## Conocimiento para el agente

Detectar arquitecturas como:

- Monolito
- Microservicios
- Hexagonal
- Clean Architecture
- Onion
- MVC
- MVVM
- Event Driven
- Serverless
- Modular

Justificar brevemente la arquitectura detectada.

## Resultado esperado

Guardar en MCP Memory la arquitectura identificada asociada al `audit_id`.
