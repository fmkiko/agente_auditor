# Skill: analizar-estructura

## Objetivo

Descubrir cómo está organizado el proyecto.

## Cuándo debe utilizarse

Después de identificar el stack tecnológico.

## Conocimiento para el agente

Analizar la estructura del proyecto identificando:

- Directorios principales
- Módulos
- Componentes
- Servicios
- Librerías
- Capas
- Configuración
- Puntos de entrada

No evaluar la calidad del código.

## Resultado esperado

Guardar en MCP Memory la estructura lógica del proyecto asociada al `audit_id`.
