# Skill: detectar-dependencias

## Objetivo

Descubrir las dependencias relevantes del proyecto.

## Cuándo debe utilizarse

Después de identificar la arquitectura.

## Conocimiento para el agente

Identificar:

- Librerías
- Frameworks
- SDKs
- APIs externas
- Servicios Cloud
- Dependencias internas
- Gestores de dependencias

No analizar vulnerabilidades.

## Resultado esperado

Guardar en MCP Memory todas las dependencias detectadas asociadas al `audit_id`.
